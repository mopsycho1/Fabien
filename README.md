# Fabien: Of Gods & Men

A story-driven tactics game that runs in a phone browser. Built with Phaser 3 and Vite.

## Play it

Open the game link (GitHub Pages) on your phone or computer. Every push to `main`
publishes a new version within 1 to 2 minutes.

## Run it on your own computer

    npm install
    npm run dev

Then open the address it prints (for example http://localhost:5173).

## Edit the story

All story text, characters and battle numbers live in `src/data`.
See HOW-TO-EDIT-THE-STORY.md for a plain-language guide.
